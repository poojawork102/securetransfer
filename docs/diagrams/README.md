# Diagrams

Export the SVGs from the "How it works" tab as PNG for the PPT and report.

Open the dashboard, go to the "How it works" tab, right-click each SVG and
save as PNG, or use a screenshot tool at 2x resolution.

Required exports:
1. architecture.png - Client, Proxy, Server, Dashboard
2. frame_format.png - 17-byte header fields
3. sequence.png - Stop-and-wait ARQ exchange
